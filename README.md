# ⚙️ Flexterion — Инженерный комплекс ЧПУ

**Flexterion** — настольный инженерный программный комплекс и справочник для технологов, программистов и операторов станков с ЧПУ.

Приложение объединяет расчёт режимов резания по стандарту **ISO 513**, интерактивную графическую аналитику, справочник **ГОСТ / ЕСДП** с нативным просмотрщиком PDF, геометрические решатели и генерацию управляющих программ (G-кода) для токарных и фрезерных станков.

---

## 🎯 Основные возможности

### 🔄 Ролевая адаптация интерфейса
Мгновенное переключение между двумя режимами работы в шапке приложения:
* **Оператор** — лаконичный интерфейс у стойки станка с фокусом на быстрые расчёты, проверку размеров и готовые циклы УП.
* **Инженер** — расширенная аналитика, инженерные графики, подбор твёрдых сплавов, СОЖ и детальные технологические параметры.

---

### 📐 Общий инженерный блок
* **Допуски и посадки (ЕСДП / ГОСТ 25347):** расчёт предельных отклонений, визуализация полей допусков и цеховая диагностика фактического размера («Годен», «Исправимый брак», «Неисправимый брак»).
* **Справочник резьб:** расчёт исполнительных диаметров ($d, d_2, d_1$) и подбор свёрл под метрическую, трубную и трапецеидальную резьбу с учётом материала заготовки.
* **Материаловедение и ISO 513:**
  * Классификатор 6 групп обрабатываемости (`P, M, K, N, S, H`), база марок сталей и сплавов (`ГОСТ / DIN / AISI / GB`), конвертер твёрдости (`HRC ↔ HB ↔ HV ↔ σв` по ГОСТ 22761 / ISO 18265).
  * Интерактивные графики: $V_c(\text{HB})$, удельная сила резания $k_{c1.1}(\text{HB})$, подача $f(\text{HB})$, индекс обрабатываемости $K_m(\%)$, подбор сплава и режима СОЖ.
* **Каталог ГОСТ и ЕСКД:** структурированная база из 8 разделов (ЕСДП, резьбы, конструктивные элементы, металлы и прокат, режущий и измерительный инструмент, ЕСКД, крепёж, подшипники и уплотнения) с быстрым поиском и нативным просмотром PDF.

---

### 🔩 Токарная обработка (`Turning`)
* **Шапка программы:** генерация безопасного заголовка УП под стойки **Fanuc**, **Siemens** и **НЦ-31**.
* **Режимы резания и аналитика:**
  * Расчёт $V_c, n, f_n, V_f, a_p$, ограничителя оборотов `G50`, симуляция разгона шпинделя (`G96`/`G97`) и теоретической шероховатости $Ra / Rz$ по радиусу пластины $r_\varepsilon$.
  * Интерактивные графики: кривая стойкости Тейлора $T(V_c)$, семейство парабол шероховатости $Ra(f_n)$ (ISO 1832), мощность резания $P_c(a_p)$ и профиль оборотов $n(D)$ с отсечкой `G50`.
* **Геометрия и циклы (6 решателей):**
  * Расчёт токарных фасок и траектории подвода резца.
  * Круговая интерполяция (`G02/G03` через `R` и `I, K`).
  * Расчёт глухих отверстий, заборного конуса сверла и циклов сверления (`G81/G83`).
  * Решатель токарных конусов ЧПУ (включая конусы Морзе и 7:24) и прямоугольных треугольников.
  * Прямоугольные канавки и отрезка с циклом `G75` (числовой и параметрический с `#`-переменными).
  * Сопряжение «Конус — Цилиндр» дугой радиуса $R$ с компенсацией радиуса пластины $r_\varepsilon$ без `G41/G42`, векторным эскизом и генерацией G-кода.

---

### 🌀 Фрезерная обработка (`Milling`)
* **Шапка программы:** формирование стартового блока фрезерной УП.
* **Режимы фрезерования и аналитика:**
  * Расчёт $V_c, n, f_z, V_f, a_p, a_e$, эффективного диаметра $D_{\text{eff}}$ для сферических фрез (`BallNose`) и фрез с круглыми СМП (`RoundInsert`), компенсация утонения стружки $h_m$, объёмный съём $Q$, крутящий момент $M_{\text{кр}}$ и загрузка шпинделя (%).
  * Интерактивные графики: коэффициент утонения стружки $k_{hm}(a_e / D_c)$ с зоной HSM/трохоидальной обработки, загрузка двигателя $P_{\text{mot}}(a_p)$, эффективный диаметр $D_{\text{eff}}(a_p)$ и кривая стойкости Тейлора $T(V_c)$.
* **Геометрия и циклы:** расчёт координат отверстий по делительной окружности (`PCD`) и сетке с поворотом, винтовая интерполяция (`Helical`), резьбофрезерование и жёсткий метчик (`G84`), расчёт шага строчки 3D-фрезерования по высоте гребешка (`Scallop`).

## 🛠 Технологический стек и архитектура

* **Платформа:** C# / .NET 9 (`net9.0-windows10.0.19041.0`), WPF.
* **Архитектура:** MVVM с полной изоляцией расчётной логики в сервисах за интерфейсами, ленивой инициализацией и кэшированием экранов (`CachedScreens`).
* **UI-фреймворк:** `MaterialDesignThemes` (`v5.4.0`).
* **Графика и файлы:**
  * Нативный рендеринг интерактивных графиков и векторных эскизов на WPF `Canvas` без сторонних графических библиотек (совместимо с `PublishSingleFile`).
  * `Windows.Data.Pdf` (WinRT) — встроенный рендеринг страниц ГОСТ в окне `GostPdfViewerWindow`.
* **Системные механизмы:** контроль единственного экземпляра приложения через глобальный `Mutex`, валидация числового ввода через `NumericInputBehavior`.

## 🚀 Сборка и запуск

### Требования
* Windows 10 (версия 1903 / build 18362 и выше) или Windows 11
* [.NET 9.0 SDK](https://microsoft.com)
* Visual Studio 2022 (17.12+) с рабочей нагрузкой *«Разработка классических приложений .NET»*

### Запуск из исходного кода
```bash
git clone https://github.com/Chedser/flexterion-solver.git
cd flexterion-solver
dotnet restore
dotnet run
```

*(Примечание: PDF-файлы стандартов располагаются в директории `Assets/GOSTs/` и автоматически копируются в выходной каталог при сборке).*

---

### Публикация и создание установщика (Windows x64)

Для распространения приложения на компьютеры без установленного .NET 9 Runtime выполняется автономная публикация (`Self-Contained`) с последующей упаковкой в инсталлятор:

1. **Автономная сборка релиза:**
   Запустите скрипт `publish.bat` в корне репозитория или выполните команду:
   ```bash
   dotnet publish MechCore.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./publish
   ```
   В результате в директории `./publish` будут собраны исполняемый файл `Flexterion.exe` и папка `Assets/GOSTs/` со справочной документацией.

2. **Сборка установочного пакета (Inno Setup):**
   * Установите [Inno Setup 6](https://jrsoftware.org "Inno Setup download").
   * Откройте файл сценария `installer.iss` в **Inno Setup Compiler** и запустите компиляцию (`Ctrl + F9`).
   * Готовый установщик `Flexterion_Setup_v1.0.exe` будет сохранён в директории `./InstallerOutput/`.

> 💡 **Для конечных пользователей:** готовый установочный файл можно скачать напрямую в разделе [Releases]([https://github.com](https://github.com/Chedser/flexterion-solver/releases) "Flexterion Releases") репозитория — установка .NET SDK для работы программы не требуется.
